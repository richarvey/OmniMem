# Atlas evidence

The [Agent Memory Atlas](https://neoneye.github.io/agent-memory-atlas/systems/omnimem/) reads a memory system's code at a pinned commit and marks what it does: each mark is earned or withheld from what the code enforces, not from what the docs say. Its review of 7.0.5 (pinned at `3790d5b7`) is where 7.0.6 and 7.0.7 came from.

This page is the other half: for each mark, where the code that earns it is and which test fails without it, so a re-pin can check the claim in minutes rather than hunting for it. The status column is OmniMem's own reading. Only the Atlas's says whether a mark is held.

Line numbers are for 7.0.7. Update this page in any release that touches a mark.

## How to read a row

- **Where** is the code that enforces the mark: remove it and the behaviour goes.
- **Test** is one that fails if that code is removed. For the negative-recall suite this was checked by hand when it was written, by breaking each predicate and watching its test fail.
- **Notes** are the limits, stated plainly, so a reviewer doesn't have to find them.

A mark OmniMem claims but the Atlas hasn't re-read yet is "claimed". "Not yet" means there is nothing to point at, and the release it's planned for.
